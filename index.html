What the demos do, and do not do.

Is there live AI behind the demos?

No. Every response is produced by deterministic JavaScript rules in this browser. There are no model calls, API requests, credentials, or connected client systems.

What happens to the information I type?

It stays in this page's memory and disappears on reload or navigation. No analytics, database, local storage, or sends. Downloaded receipts are files you choose to keep. Use fictional information only.

Does approval send a reply or publish a website?

No. Request and answer approvals produce local receipts only. Website publishing changes the fictional preview in this tab, not any real website.
